# balegram

Modern, fully-typed, asynchronous framework for the [Bale](https://bale.ai) Bot API.

- Routers (nestable), middlewares (outer / inner), composable filters
- Pydantic v2 models for every Bale type, typed method objects
- Finite state machine with pluggable storage
- Long polling and webhook runners
- Python 3.10+

> Work in progress. See the commit history for what has landed.
